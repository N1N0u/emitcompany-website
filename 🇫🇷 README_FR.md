## 📌 À propos
Ce projet représente le site web corporate développé pour **EMIT Company**, spécialisée dans :  
- Installations électriques  
- Montage de tableaux électriques  
- Travaux BTP  
- Systèmes de vidéosurveillance & CCTV  
- Maintenance préventive et corrective  

L’objectif du site est de présenter les services, l’expertise et les informations de contact de l’entreprise de manière professionnelle et responsive.

---
## 🛠 Technologies utilisées

### Frontend
- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript  

### Backend
- PHP (traitement du formulaire de contact et validation côté serveur)

### SEO & Optimisation
- sitemap.xml  
- robots.txt  
- Design responsive mobile-first  
- Assets optimisés

### Hébergement & Déploiement
- Hébergement mutualisé (cPanel)  
- Déploiement via FTP

---
## ⚙ Fonctionnalités clés
- Design totalement responsive

- Optimisé SEO
