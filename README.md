---
## 📌 Project Overview
This project represents the corporate website developed for EMIT Company, a company specialized in:
- Electrical installations
- Electrical panel assembly
- BTP works
- CCTV & surveillance systems
- Preventive and corrective maintenance
The objective of the website is to present the company’s services, expertise, and contact information in a professional and responsive digital format.
---
## 🛠 Technologies Used
### Frontend
- HTML5
- CSS3

- JavaScript
### Backend
- PHP (Contact form processing & server-side validation)
### SEO & Optimization
- sitemap.xml
- robots.txt
- Mobile-first responsive design
- Optimized assets
### Hosting & Deployment
- Shared hosting (cPanel)
- FTP-based deployment
